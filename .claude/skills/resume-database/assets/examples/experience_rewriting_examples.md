# 经历包装示例

## 参考素材示例

`data/experience_library/user_growth_analysis.md`：
```markdown
# 用户增长数据分析项目

## 项目背景
某在线教育平台希望提升新用户留存率。

## 分析思路
1. 收集用户行为数据（注册、登录、课程学习、付费）
2. 使用SQL提取数据，Python进行清洗和分析
3. 使用漏斗分析找到流失节点
4. 提出优化建议

## 使用工具
- SQL（数据提取）
- Python + Pandas（数据清洗和分析）
- Tableau（可视化）

## 关键发现
- 新用户在首次登录后24小时内流失率最高（65%）
- 完成首次课程学习的用户留存率提升至80%

## 优化建议
- 优化新手引导流程
- 推送个性化课程推荐
```

## 引导候选人示例

```
这个项目参考了用户增长数据分析的思路。你需要自己完成以下操作：

1. 找一个公开数据集（如Kaggle上的电商数据、APP使用数据）
2. 使用SQL或Python提取数据，分析用户行为
3. 使用漏斗分析或留存分析找到关键节点
4. 做一个简单的可视化图表（用Excel、Tableau或Python都可以）
5. 写一份1-2页的分析报告，总结发现和建议

预计耗时：4-6小时

完成后，把你的数据集、分析过程和报告发给我。
```

## 候选人完成后的经历（正确示例）

假设候选人使用Kaggle的电商数据完成了分析，按STAR法则写成：

```markdown
## XX电商用户留存分析项目
**时间；** 2026年9月 - 2026年10月

- **背景与任务：** 基于Kaggle公开电商数据集（5000+用户），分析用户留存情况，识别流失节点
- **行动：** 使用Python和Pandas清洗和分析用户行为数据，通过漏斗分析定位关键流失环节，使用Tableau可视化留存曲线和转化漏斗
- **结果：** 发现新用户首日留存率仅42%，首次浏览后未加购的流失率达68%；输出数据分析报告，提出优化新手引导和个性化推荐的建议
```
