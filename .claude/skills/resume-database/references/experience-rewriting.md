# 经历改写与包装

## 适用范围

**仅适用于：**
- 实习经历
- 项目经历

**不适用于：**
- **教育经历（学校、学历、专业、时间）** - 绝对不可包装或编造

## 核心原则：Fake it until you make it

包装遵循"先做再写"原则：
1. 候选人按参考经历实际尝试操作、工具、分析或产出
2. 先让自己"看起来像做过"
3. 通过真实尝试把"假装会"变成"真的会"
4. 把真实尝试写成自己的经历
5. **不直接背诵、移植他人描述**

## 触发条件

### 何时需要包装
- CV中的实习/项目经历与JD要求有明显gap
- 候选人主动要求参考他人经历
- 岗位画像显示需要某类经历，但CV中缺失

### 何时不需要包装
- CV中已有足够匹配的经历
- 只需调整表述，不需新增经历

## 包装流程

### 步骤1：读取参考素材
- 从`data/experience_library/<project_name>.md`读取相关素材
- 选择与JD要求最匹配的素材
- 理解素材中的思路、做法、工具和产出

**素材示例参考**[assets/examples/experience_rewriting_examples.md](../assets/examples/experience_rewriting_examples.md)

### 步骤2：引导候选人真实尝试
**明确告知候选人：**
```
这个经历参考自他人，但不能直接复制。你需要先按照这个思路实际操作一遍：

1. [具体操作步骤]
2. [使用的工具]
3. [产出的结果]

完成后，把你的真实尝试和产出告诉我，我会帮你用STAR格式写成简历经历。
```

**引导内容：**
- 需要使用的工具和数据来源
- 需要完成的具体操作（如跑数据、做可视化、写分析报告）
- 需要产出的结果（如报告、代码、可视化图表）
- 预计耗时

**引导示例参考**[assets/examples/experience_rewriting_examples.md](../assets/examples/experience_rewriting_examples.md)

### 步骤3：等待候选人完成
- 候选人实际完成操作并提供产出
- 如候选人未完成，**不写入简历**
- 如候选人完成部分，写入完成的部分

### 步骤4：将真实尝试写成经历
- 基于候选人的真实尝试和产出
- **使用STAR格式**改写成简历经历
  - **S (Situation)** - 项目背景和数据集来源
  - **T (Task)** - 要解决的分析任务
  - **A (Action)** - 使用的工具和分析方法
  - **R (Result)** - 得到的发现和输出的报告
- 融入JD关键词
- **不复制参考素材的原文**

**改写示例参考**[assets/examples/experience_rewriting_examples.md](../assets/examples/experience_rewriting_examples.md)

## 伦理说明

**本skill不标注素材来源，不做伦理审查。**

包装的核心是"Fake it until you make it"：
- 候选人通过参考他人思路，实际完成操作，获得真实能力
- 面试被追问细节时能接得住
- 候选人在包装过程中真正获得了对应能力

## 质量检查
- [ ] 候选人已实际完成操作并提供产出
- [ ] 经历描述基于候选人的真实尝试，非参考素材原文
- [ ] 经历使用STAR格式改写
- [ ] 如候选人未完成，未写入简历
