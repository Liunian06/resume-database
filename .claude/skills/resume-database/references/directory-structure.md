# 目录结构规范

> 完整的目录结构树状图见SKILL.md，本文档仅说明目录创建规则和路径规范。

## 目录创建规则
1. `data/`及其子目录在第一次使用时自动创建
2. `user_index.md`在第一个用户建档时创建
3. 用户目录在建档时创建
4. 岗位目录在建立岗位时创建
5. `raw/`目录在用户提供原始材料时创建
6. 面经库目录按需创建，不预先创建空目录
7. 证件照`photo.jpg`在候选人提供照片时放入用户根目录，不预先创建

## 路径无硬编码
- 所有路径相对于skill根目录或项目根目录
- 不依赖特定用户名、绝对路径或运行时位置
- 脚本使用相对路径或接受路径参数
