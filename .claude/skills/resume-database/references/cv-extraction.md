# CV提取与整理

## 输入来源

### 原始材料位置
`data/<user_ID>/raw/source.md`

### 材料类型
- 候选人旧简历（Word、PDF转文本、Markdown等）
- 零散描述（聊天记录、邮件、笔记）
- 草稿、未完成的简历片段
- 候选人口述的经历记录

## 提取目标

### 必提取字段
**个人信息：**
- 姓名（必须真实）
- 手机
- 邮箱
- 证件照（填“有”或“无”；有则确认已保存为`data/<user_ID>/photo.jpg`）
- 个人主页（可选）
- GitHub（可选）
- LinkedIn（可选）
- 小红书（可选）
- 抖音（可选）
- Bilibili（可选）
- Instagram（可选）
- Twitter/X（可选）
- YouTube（可选）

**教育经历：**
- 学校名称（必须真实）
- 学历（本科/硕士/博士，必须真实）
- 专业（必须真实）
- 入学时间、毕业时间（必须真实）
- GPA（格式：X.XX/满分，如3.8/4.0或4.2/5.0）
- 主要课程（可选）
- 获奖情况（可选，必须真实）

**校园经历：**
- 社团/组织名称
- 职位
- 起止时间
- 工作描述（bullet点）

**比赛经历：**
- 比赛名称
- 时间
- 获奖情况
- 比赛描述（bullet点）

**实习经历：**
- 公司名称
- 岗位名称
- 起止时间
- 工作内容（bullet点，STAR格式）

**项目经历：**
- 项目名称
- 起止时间
- 项目描述（bullet点）

**科研经历：**
- 课题/论文名称
- 起止时间
- 导师
- 成果（论文发表、专利等）
- 研究描述（bullet点）

**技能与证书：**
- 编程语言
- 框架/库
- 开发工具
- 版本控制
- 数据库
- 云平台/服务器
- 数据分析
- 办公软件
- 设计工具
- 视频剪辑
- 音频处理
- 新媒体运营
- 市场营销工具
- 财务软件
- 法律检索工具
- 项目管理工具
- 沟通协作工具
- 专业软件
- 证书资质
- 语言能力（CET-4/6、雅思、托福等）

**其他：**
- 志愿者经历
- 发表论文、专利（如未在科研经历中列出）
- 其他值得说明的信息

## 整理规则

### 教育经历真实性
- **绝对不可包装或编造**
- 学校、学历、专业、时间必须与学信网或学校官方记录一致
- 如材料中教育经历信息不清晰或可疑，必须向候选人确认

### 实习、项目、科研和校园经历
- 保留候选人提供的所有经历
- 如描述过于简单，标注"待补充"
- 如时间冲突或逻辑矛盾，标注"待核实"并向候选人确认
- 不在此步骤做包装或改写，只做事实提取

### 中英文一致性
- 同时生成`cv_CN.md`和`cv_EN.md`
- 中英文CV的事实信息必须一致
- 公司名称、学校名称使用官方英文名
- 时间格式统一：中文用"2026年1月 - 2026年6月"，英文用"Jan 2026 - Jun 2026"

## CV文件格式

参考模板文件：
- 中文模板：`assets/templates/cv_CN_template.md`
- 英文模板：`assets/templates/cv_EN_template.md`

**格式要求：**
- 使用中文全角分号`；`连接字段名和内容（中文版）
- 使用英文冒号`:`连接字段名和内容（英文版）
- 时间格式：中文用"2026年9月"，英文用"Sep 2026"（月份三字母缩写 + 年份）
- 所有"待补充"和"待核实"标注需明确标出
- 用户没有的字段留空或填写"无"

## 错误处理
- 原始材料缺失关键信息：标注"待补充"并向候选人询问
- 教育经历信息不清晰：必须向候选人确认，不可推测
- 实习/项目时间冲突：标注"待核实"并向候选人确认
- 中英文信息不一致：以候选人最新确认的版本为准，同步更新两份CV
