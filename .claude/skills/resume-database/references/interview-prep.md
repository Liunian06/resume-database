# 面试准备文档生成

## 输入内容

### 必读
- `<basename>.md` - 定向简历
- `job_profile.md` - 岗位画像

### 可选读取
- `jd.md` - JD原文
- 公共面经、个人面经

## 输出内容

面试准备文档**按面试轮次分别生成**，每轮包含3个部分：
1. **简单自我介绍**（1-2分钟，所有轮次通用）
2. **预判问题**（每轮20个：10个简历深挖 + 10个有关业务）
3. **反问**（每轮3个，根据面试官类型调整）

**重要：** 生成时要明确是哪一轮面试的准备（一面/二面/HR面），每轮的20个问题独立生成，不是总共20个。

## 1. 自我介绍

### 结构
- 基本信息（学校、专业、年级）
- 核心优势（与岗位最匹配的经历和技能）
- 求职动机（为什么申请这个岗位）

### 时长
- 1-2分钟（约200-400字）

### 表达原则
- 突出与岗位最相关的经历
- 使用JD关键词
- 简洁明了，不铺张

### 示例
```
您好，我是张三，清华大学计算机科学本科在读，目前大三。我对数据分析和产品优化非常感兴趣，曾在字节跳动担任产品实习生，负责XX功能的数据分析和A/B测试，通过数据驱动决策，帮助产品XX指标提升了18%。我也完成了一个用户留存分析项目，使用SQL和Python分析5000+用户行为数据，定位流失节点并提出优化建议。我希望加入贵司，继续在数据驱动的产品优化方向深入学习和实践。
```

## 2. 预判问题（每轮20个）

每轮面试准备20个问题：
1. **简历深挖**（10个）- 针对简历中的经历，预测面试官可能的追问
2. **有关业务**（10个）- 从面经中提取的高频问题，以及根据岗位画像预判的业务类问题

### 简历深挖问题（10个）
- 针对简历中的每段实习和项目经历
- 覆盖背景、方法、数据、成果、困难等
- **每轮都要深挖简历**：一面、二面、HR面都会追问简历细节，只是追问角度可能不同（一面偏技术执行，二面偏思考决策，HR面偏动机态度）

**示例参考**[assets/examples/interview_prep_examples.md](../assets/examples/interview_prep_examples.md)

### 有关业务问题（10个）
- 从公共面经库和个人面经中提取高频问题
- 根据岗位画像预判的业务场景问题
- 包含行为问题、案例分析、通用问题等
- 根据面试轮次调整重点：一面侧重执行能力，二面侧重战略思考，HR面侧重职业规划

**示例参考**[assets/examples/interview_prep_examples.md](../assets/examples/interview_prep_examples.md)

## 3. 反问（每轮3个）

### 反问原则
- 体现对公司和岗位的了解
- 展现学习意愿和职业规划
- 避免问薪资、加班等敏感问题（留到HR面或offer阶段）
- **优先问能补充岗位画像的信息**：实际工作内容、技术栈、团队构成、考核重点等，这些答案可以直接用于后续简历调整和下一轮面试准备

### 反问倾向
根据面试轮次和面试官类型，调整反问重点：

**一面（技术面/业务面）：**
- 优先问实际工作内容、技术栈、团队日常
- 这些信息对理解岗位最有价值，且面试官最清楚

**二面（总监面）：**
- 问团队文化、发展路径、业务战略
- 补充业务线定位和公司背调的信息

**HR面：**
- 问培养机制、晋升路径、后续流程
- 适当涉及薪资、入职时间等实际问题

**示例参考**[assets/examples/interview_prep_examples.md](../assets/examples/interview_prep_examples.md)

## 输出文件

### 文件位置
`data/<user_ID>/jobs/<company>-<position>/<basename>_interview_prep.md`

### 文件格式
按模板[assets/examples/interview_prep_examples.md](../assets/examples/interview_prep_examples.md)填写，注意：
- 按面试轮次分段生成（一面准备、二面准备、HR面准备）
- 每轮包含：简历深挖10个 + 有关业务10个 + 反问3个
- 自我介绍所有轮次通用，放在最前面

## 回答准备建议

在文档末尾附上通用的回答准备建议（所有轮次共享），具体内容参考[assets/examples/interview_prep_examples.md](../assets/examples/interview_prep_examples.md)

## 质量检查
- [ ] 自我介绍突出与岗位最匹配的经历
- [ ] 每轮面试准备了20个问题（10个简历深挖 + 10个有关业务）
- [ ] 简历中的主要经历都有对应的深挖问题
- [ ] 每轮有3个反问，且根据面试官类型调整了侧重点
- [ ] 如有面经，提取了高频问题
- [ ] 一面反问优先关注实际工作内容和技术栈
