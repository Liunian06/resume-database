# 用户管理

## 用户索引文件

### 文件位置
`data/user_index.md`

### 文件格式
```markdown
# 用户索引

| user_ID | 姓名 | 学校 | 专业 | 创建时间 | 最后更新 |
|---------|------|------|------|----------|----------|
| 10001 | 张三 | 清华大学 | 计算机科学 | 2026-10-15 | 2026-10-16 |
| 10002 | 李四 | 北京大学 | 经济学 | 2026-10-16 | 2026-10-16 |
```

### 创建索引
- 第一次建档时创建`data/user_index.md`
- 包含表头和第一条用户记录

## 建档流程

### 检查用户是否存在
1. 读取`data/user_index.md`
2. 通过姓名、学校或user_ID查询
3. 如已存在，返回user_ID并定位到用户目录

### 创建新用户
1. 询问候选人基本信息：姓名、学校、专业
2. 分配user_ID（读取索引中最大user_ID + 1，从10001开始）
3. 创建用户目录`data/<user_ID>/`
4. 创建子目录`data/<user_ID>/raw/`和`data/<user_ID>/jobs/`
   - 如果候选人提供了证件照，保存为`data/<user_ID>/photo.jpg`（保留原扩展名），之后所有简历复用
5. 更新`data/user_index.md`，添加新用户记录
6. 记录创建时间和最后更新时间（格式：YYYY-MM-DD）

### 更新用户信息
- 每次修改用户数据时，更新`user_index.md`中的"最后更新"字段
- 如用户补充或修改基本信息（学校、专业等），同步更新索引

## 定位用户
### 按user_ID定位
- 直接访问`data/<user_ID>/`

### 按姓名定位
- 读取`data/user_index.md`
- 查找姓名匹配的记录
- 如重名，提示用户选择（列出学校、专业等信息）

## 错误处理
- user_ID已存在：报错并建议使用已有user_ID
- 索引文件损坏：尝试从`data/`目录下的用户目录重建索引
- 用户目录缺失但索引存在：警告并询问是否重建用户目录
