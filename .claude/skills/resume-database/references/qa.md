# 常见问题与联系开发者

## 何时联系开发者

遇到以下情况时，停止反复尝试，向用户说明情况并提供开发者联系方式：

- skill运行中出现无法解决的错误：已按对应references排查（如[setup.md](setup.md)的环境检查、[docx-generation.md](docx-generation.md)的转换规则），重试后仍失败
- 出现未知错误：报错信息无法定位原因，或脚本行为与文档描述不一致
- 疑似skill本身的缺陷：模板、脚本或规则存在明显错误

## 联系前先梳理问题

联系开发者前，agent应先帮用户把问题整理成以下三部分，便于开发者快速定位：

1. **Bug现象**：在哪个步骤、执行了什么操作、期望结果与实际结果分别是什么，附完整报错信息（不要只截取最后一行）
2. **如何复现**：列出可重复的操作步骤，包括调用的脚本与参数、输入文件类型、操作系统与Python版本、skill版本号（见`SKILL.md`的`version`）；如只在特定数据下出现，说明数据特征而非直接附原文件
3. **可能的解决方案**：agent根据报错和已做的排查，给出对原因的判断和可能的修复方向，并注明已经尝试过哪些方法、各自结果如何

整理好后以一段可直接复制的文本交给用户。整理内容中须删除个人隐私（姓名、手机号、邮箱、身份证号等）。

## 联系方式

扫描交流群二维码联系开发者：`assets/qrcode.png`

告诉用户二维码图片位于skill目录下的`assets/qrcode.png`，可直接打开扫码加入交流群，并把上面整理好的问题描述发给开发者。

也可以在GitHub仓库提交Issue：https://github.com/Liunian06/resume-database/issues
